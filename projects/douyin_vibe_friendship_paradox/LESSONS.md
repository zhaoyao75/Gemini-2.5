## 3. 内容经验（来自赛道研究，详见 research 文档）

- 选题公式：硬知识 + 和"你"有关 + 一个反直觉数字。友谊悖论对应"刷朋友圈的焦虑"。
- 六段式：钩子 → 历史出处 → 机制动画 → 反直觉转折 → 落点 → 收尾。本片压缩到约 62 秒（原片 2–2.7 分钟）。
- 同质化是最大风险：深色底 + 发光线条 + 粒子 + 电子配乐。本片的区分点是「黑金星网」母题和真实论文复原，选题避开了熵增、囚徒困境等被讲烂的。
- 字幕说到的东西，画面上必须真的出现（本片所有数字都由画面里的网络动画算出或直接画出）。

**待验证（发布后回填）**：横屏 1920×1080 是否适合抖音（抖音以竖屏为主，原片规格是横屏，未验证两者效果差异）；3 秒完播、点赞、评论等数据；是否需要出 9:16 竖版。

## 4. 技术经验

**架构**：单个 HTML 里 `render(t)` 是时间的纯函数（不用 requestAnimationFrame、Date、无种子随机）→ Playwright 逐帧截图（4 个页面并行）→ ffmpeg 合成；配乐和音效用 numpy 合成，场景切换和音效全部按拍点对齐。全片渲染约 2 分钟。

**时间线驱动**：`timeline.json` 里场景和音效用「拍」定义，`T(beat)` 把拍映射成秒（标题卡 `intro_seconds` 之后按拍顺延）。改 BPM、改标题卡长度、增删场景只改 JSON，不动动画代码。注意：**改 BPM 会按比例拉长/缩短全片**（实际发生过：92 → 77 BPM，全片从约 57 秒变成 65 秒），要保时长需同时调拍数。

**字体**：系统只有文泉驿黑体，用 npm `@fontsource` 装思源宋体/黑体和 EB Garamond。加载时要用"全文字符串"触发字体分片下载；EB Garamond 只装了斜体，所以西文一律用斜体。

**质检三件套**（每次改完都做）
1. 关键帧拼图：`node src/render.js --keyframes` 出 16 帧拼图，先看构图再出全片。
2. 自动检测：`ffprobe` 看规格；`ffmpeg -af ebur128` 看响度（目标 -14 LUFS）；逐帧运动量；"空画面扫描"（亮度>40 的像素占比<0.25% 判为空），最终最长空画面 0.2 秒。
3. 从成片抽帧看关键时刻（开头、转场、结尾）。**自动检测有盲区**：我写的"标题可见帧"检测被后续画面干扰，给出了错误结论，最后靠人眼看抽帧才确认。

**踩过的坑**
| 问题 | 原因 | 解法 |
|---|---|---|
| 第 0 帧是空的 | 元素都从 0 开始入场 | 首个元素的窗口起点设为负数；卡片带入场偏移 |
| 6 人网一直画到片尾 | 场景函数没有结束条件 | 每个场景必须有淡出，包一层 `globalAlpha` |
| 相邻两句字幕之间有约 0.7 秒暗区 | 前一句淡出、后一句淡入首尾相接 | 可接受；要紧凑就缩短淡入淡出 |
| 新页面淡入时叠着上一段字幕残影 | 淡入起点早于上一段结束 | 淡入起点推迟到上一段结束之后 |
| 同侧滑入的两张卡片中途互相压住 | 错开入场的先后顺序与位置相反 | 离入口近的先到 |
| 响度 -11.2 LUFS 太响 | 以 RMS -13 为目标 | RMS 目标 -16，得到 -14.5 LUFS；一律用 LUFS 表复核 |
| 配乐听感无法确认 | 代码合成，我听不到 | 只能靠峰值/响度数值；需要人耳终审，或换授权音乐再做节拍对齐 |
| 论文 PDF 网页工具读不出 | 二进制压缩流 | 下载到本地，`pdftotext`/`pypdf` 提取全文再 grep |
| 提交 mp4 导致仓库膨胀 | 每版 6–17MB，改了十几版 | 归档前把历史整理成几个提交，只留终版 |

## 5. 数据与事实核查经验

- **一律以原文为准，二手来源的数字会走样**：二手报道写 93%，原论文是 **92.7%**（Ugander 等 2011，arXiv:1111.4503）。视频里已改为原文数字。
- 已对照原文核实：721 million 活跃用户（2011 年 5 月）；平均约 190 个好友；随机一条友谊连线另一端平均 635 个好友（k²/⟨k⟩，按连线平均）；92.7% 的用户好友数少于其朋友的平均好友数（另有 83.6% 少于朋友好友数的中位数）；Feld (1991), AJS 96(6): 1464–1477。
- 画面里的示意数字由示意网络实际算出（平均 3.44，朋友的平均 3.97），不是编的。
- **没有出处的叙述必须标"示意"**：「热闹的人往往发得也多」没有文献支撑，对应画面标注"示意动画，非真实数据"。若想完全严谨，可删这一段（约 6 秒）。
- 其他备选选题里的数字**尚未核实**：峰终定律"约七成选长的那次"、本福特定律"用于查假账"、辛普森悖论的肾结石数据——用之前先查一手来源。
- 关于配乐「开智小曲」：没有找到可靠的实测 BPM；最接近的证据是 8 条原片配乐 76–78 BPM；网上出现的 113 BPM 属于另一首曲子；多个仓库说明该曲有版权，需自行取得授权。
