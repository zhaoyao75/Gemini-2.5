# 牡丹静物 · 多画家风格

同一幅构图，换一个风格文件就能换成另一位画家的画法。

## 结构
- `scene.js`：共用的构图，所有风格都一样。包括墙面、桌面（水平线）、花瓶、11 朵牡丹（含花苞和一朵落花）、叶、茎、投影、光源方向。
  - `SCENE.region(u, y)` 返回某一点属于哪个区域：`wall` / `table` / `vase` / `stem` / `leaf` / `bloom`，以及该点在区域内的局部参数（花心距离、角度、瓶身左右位置等）。
  - 牡丹特征都做在构图层：重瓣花由 4–5 层褶皱花瓣组成，花朵分 semi（露出金黄花蕊）、double（中心是碎瓣）、bud（圆球花苞带萼片）三种；叶子是三出复叶，每个小叶再分三裂。`region()` 返回花瓣所在的层（ring）、编号（petal）、从根到尖的位置（along）、横向位置（s）和朝向（pang），风格文件可以据此逐瓣着色。
  - 花瓶是青花赏瓶（玉壶春瓶形制）：撇口、细长颈、梨形垂腹、圈足。纹样分段：口沿弦纹、颈部蕉叶纹、肩部如意云头、腹部缠枝牡丹、胫部莲瓣纹、足部弦纹。`region()` 对瓶身返回 `zone`（所在纹样带）和 `c`（钴蓝浓度：0 白釉、约 0.4 淡染、1 深蓝），各风格据此表现青花。
  - 每朵花有 `role` 字段，取值 a/b/c，分别表示主色、副色、浅色。具体用什么颜色由各风格决定。
- `painter.js`：通用绘画工具。包括厚涂笔触、按方向场走笔、逐像素平涂和叠加（`overlay`）、花瓣与瓶身勾线、画布纹理。
- `styles/<名字>.js`：风格文件。只需定义 `color()`、`angle()`、`paint()` 三个函数。
- 渲染命令：`node render.js <风格名> <输出.png> [宽度，默认900]`

## 现有风格
- `composition`：构图参考，平涂。
- `vangogh_sunflowers`：梵高《向日葵》风格。

## 后续风格（规划）
| 画家 | 做法 |
|---|---|
| 塞尚 | 块面笔触、多视点、冷暖色块塑形 |
| 蒙克 | 波浪状长笔触、不安的色彩 |
| 克里姆特 | 金色平涂、几何纹样、花朵装饰化 |
| 马蒂斯 | 大面积纯色平涂、粗黑轮廓、墙面装饰纹样 |
| 毕加索 | 立体主义：沿网格切成多面体碎片、灰褐色调 |
| 康定斯基 | 区域转为圆、线、三角，保留大致布局 |
| 蒙德里安 | 区域量化到网格，红黄蓝加黑线 |
| 达利 | 花瓶和花朵沿垂直方向"融化"变形，长投影 |
| 波洛克 | 区域颜色作为滴洒线条的色源，形体模糊 |
| 莫奈（备选） | 短小碎点笔触、光色、无轮廓 |
