# 《问道》—— 一个少年找“道”的故事 · 竖版分镜 v2

- 画幅：竖版 9:16；标清版 540×960（制作时 2 倍分辨率绘制再缩小），30fps
- 时长：约 100 秒，12 个镜头
- 风格：黑底 + 反白水墨（山水用灰阶墨晕，人物用“火柴人骨架 + 水墨衣袍”）
  - 火柴人：米白笔触画四肢和头，线条有粗细变化，像毛笔
  - 水墨：衣袍、胡子、青牛、山石用半透明灰墨晕染，边缘柔化
  - 点缀色：朱砂红（印章、关键物件），暗金（光、月）
- 讲法：不讲经文，讲一个故事。经文只在每一回结尾出现一句，作为“老人留下的话”

## 节奏规则

1. 每 2–3 秒必须有一个动作或画面变化，不留空镜。
2. 每个镜头同时有三层信息：人物动作 + 字幕 + 顶部/底部的固定信息条。
3. 金句只在一回的高潮出现一次，用书法大字盖印出场。
4. 动画占画面时间 ≥ 80%，纯文字画面不超过 2 秒。
