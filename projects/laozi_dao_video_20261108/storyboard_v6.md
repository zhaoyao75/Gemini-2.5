# 《水与石》—— 12 秒竖版分镜 v6（金黑像素风，参考“朱元璋”人生曲线图）

故事、镜头、12 秒时间轴与 v5 相同（2 / 2 / 3.5 / 2 / 2.5 秒），只换画面风格。无旁白、无字幕。

## 风格（参考图提取）

| 参考图元素 | 这一版的做法 |
|-----------|--------------|
| 纯黑底 + 金色发光 | 黑底带一点暖色渐变；所有“光”（火星、水、涟漪、曲线）统一成金色，水改为发光金白色 |
| 像素小人 + 放射光芒 + 发光平台 | 少年、断剑、石头、水滴都用 6 倍像素块绘制；少年身后有放射金光，脚下有发光平台条；长袍改成金黄色，红发带保留作识别色 |
| 像素字体 | 标题、拟声字（铛！滴 咔！）、标签、原文全部用点阵像素字体 |
| 金色发光曲线 + 年份方框节点 | 第 3 镜的“1天 / 1年 / 10年”改成一条发光金线上的三个方框节点（石头被滴出的坑越来越深），字号 100 / 120 / 140，线的终点是发光亮点和飘散的像素碎屑 |
| 关键词金色高亮 | 结尾原文里“水”“莫之能胜”用金色，其余白色 |
