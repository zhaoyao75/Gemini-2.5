## 动画设计（大象和驴讲故事，数字尽量少）
- 吉祥物：共和党=红色大象，民主党=蓝色驴，全部用 Canvas 画（`elephant()` / `donkey()`，有表情、跳跃、走路）。
- 沿用 all_nighter 的动画语言：背景一只淡淡的大天平、标题卡砸下 + 闪光、转场交叠推镜、奶油卡片、红章、分步编排的收尾。
- 场景（66 BPM，共 90 拍）：标题（象和驴）→ 任期钟走到一半 + 选票进国会 + 介绍两大政党 → **国会的门**（象开门，驴摔门，议程盖章"推不动"）→ **气球**（象的席位被期中的大风吹走）→ 选前（象撑起白宫和两院）→ **天平**（7 个席位从象的一边跳到驴的一边，天平在第 44 拍落拍时压过去）→ **涂料桶**（驴把众议院漆成蓝色）→ 德州旗变蓝 → 三个原因填满"选民不满"条 → 议长讲台换人 → 国会调查 / 立法僵局 / 2028 → 收束提问。
- 配乐：`src/bgm.py`，明亮 G 大调，马林巴主旋律（D4–D5）+ 轻快 Euclidean 鼓点，无人声无音效；落拍前两拍只撤掉鼓和旋律，垫底和低音不断（符合"无静音、无爆点"）。`exports/music_preview.mp3` 是单独的试听文件。

## 重新出片
```bash
npm install
python3 src/bgm.py                          # 先出音频（约 10 秒），试听确认
node src/render.js --keyframes              # 关键帧拼图
node src/render.js                          # -> exports/us_midterms_90s.mp4（约 2.7 分钟）
```
改 BPM 会按比例拉长/缩短全片（66 BPM × 94 拍 = 83.3 秒）；要保时长需同时调拍数。
